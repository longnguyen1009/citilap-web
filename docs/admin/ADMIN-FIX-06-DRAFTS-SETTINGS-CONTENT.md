# Antigravity — vòng 06: Không mất nháp trong Admin

Chỉ chạy khi Codex giao. Đọc review page findings và source mới nhất. Shared autosave/DraftRecovery đang có tiến trình khác sửa; không đè diff. Review phần mới trước, patch phần thiếu; không tạo hook/framework thứ hai. Phạm vi hook/recovery/Builder/Product/Posts/StaticPage/Navigation/Categories/Settings nếu cần integration. Không sửa storefront/deploy/remote writes.

1. Settings handleSave hiện thay settings bằng response và dirty=false vô điều kiện. Capture snapshot submitted + latest ref; cập nhật revision nhưng chỉ replace nội dung khi không có edit mới. Nếu edit mới, giữ settings và dirty=true. Không xóa backup của edit mới. Async video fetch cũng phải merge vào state mới nhất, không closure cũ. Save/refresh/restore cùng lock, route reload có confirm dirty.
2. Local recovery debounce, không server autosave hoặc publish. Bản mới và bản có ID đều được bảo vệ. Payload version, actor ID, entity type/id, baseRevision, savedAt; key theo actor+entity. Không lưu token/password/PII không thuộc draft. Chặn restore nháp tài khoản khác. Server revision lệch phải cảnh báo, không tự tăng expectedRevision để overwrite. Validate schema trước restore, lưu raw JSON export khi snapshot không tương thích để tránh mất dữ liệu.
3. Không xóa backup chỉ vì server load xong/dirty=false hoặc revision vừa tăng, trừ khi backup tương ứng snapshot vừa lưu. First save/new route chuyển ID không mất edit mới. Recovery phải được phát hiện trước khi effect backup ghi đè bản cũ. Multi-tab không xóa nháp mới từ tab khác. Storage bị chặn/quota/corrupt báo rõ, vẫn cho manual save; flush pagehide/visibility nếu hợp lý. Không báo đã backup khi setItem thất bại.
4. Ctrl/Cmd+S đúng draft mới nhất, prevent browser save, không double listeners, không save khi loading/saving/disabled, bỏ qua key composition nếu cần. Hook hiện có listener từ tiến trình khác; rà integration thay đăng ký mới.
5. Posts/StaticPage restore confirm có cảnh báo rõ khi dirty; cancel giữ nguyên doc/revision; restore request không ghi đè edit gõ trong lúc chờ. History lỗi phải có feedback thay im lặng. Conflict dùng error HTTP status từ mediaRequest sau vòng 01 thay so chuỗi. Product search debounce+abort/generation để kết quả cũ không ghi đè.
6. Categories bỏ beforeunload trùng với hook, Navigation/Categories recovery dùng cùng quy tắc identity/revision. Không tự publish khi restore. Giữ request locks/latest refs đã có.

Regression runnable cho storage recovery và request race bằng harness hiện có; browser desktop gồm gõ nhanh trong request save chậm, reload/crash giả lập, 401/409, account khác, new entity sau first save, hai tab, storage throw, corrupted backup, cancel restore, Ctrl+S một request. Báo mock-browser khác persistence thật. Typecheck/lint/test; ACK/report round-06-report.md; NEEDS_REVIEW rồi chờ Codex.
